# glossary

## terms

- **index** - the in-memory file tree. See [the api](api.md#the-walker).
- **previewable** - a `.md` or `.mmd` file. See [extensions](api.md#previewable-extensions).
- **live reload** - SSE-driven refresh. See [events](api.md#get-apievents).
