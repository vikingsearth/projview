# troubleshooting

## diagram won't render?

Check the browser console - a malformed diagram shows an inline error card
instead of taking down the page. See [the broken diagram](../diagrams/broken-diagram.mmd).

## link goes nowhere?

Internal links to files that don't exist show a "not found" state. Example of a
link to a file in a folder that doesn't even exist:

[ghost doc](../nope/ghost.md)

## still stuck?

Open an issue (external): [github](https://github.com/anthropics/claude-code/issues).
